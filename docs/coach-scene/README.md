# Homepage coach scene: source

- `coach-scene-static.svg` is the approved-pose illustration (the still used for reduced motion and before the
  animation starts). It opens in Figma, Illustrator, Inkscape or any browser. Every body part is its own named
  group (`cl-` client, `co-` coach; `th` thigh, `kn` knee/shin, `ft` foot, `sh` upper arm, `el` forearm, `hd` head,
  `n` near side, `f` far side), so parts can be restyled without breaking the rig.
- The live artwork and animation are generated by `coachSceneSVG()` and `makeCoachScene()` in `vf26/vfit-2026.js`.
  Change colours and proportions in the `csPerson(...)` options there; the SVG file here is an export of that code.
- Walking cycle: `CS_GAIT` (cycle 1.12 s, stance 62 percent, stride 58 units). `csFoot()` gives the ankle path
  (heel contact, flat stance moving at belt speed, push-off over the toe, swing) and `csIK()` solves hip and knee.
  The belt pattern moves at the same speed as the stance foot, so feet do not slide.
- Re-export the SVG after changing the code: open the homepage, run
  `vfCoachScene.pause(); vfCoachScene.seek(0.18)` in the console and copy `.vfh-scene-art svg`.
